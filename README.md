# Roland Zogbay Portfolio Website

## 🚀 Project Overview

This is My **personal portfolio website**, I am a Web Developer (Frontend Developer & Backend Developer), UI/UX Designer, Problem Solver, and Graphic Designer.  

The website showcases:

- Professional projects and work experience  
- UI/UX and web development skills  
- Testimonials and feedback  
- Interactive and responsive features  
- Modern and clean design with animations  

This portfolio is designed **mobile-first**, fully responsive, and built with **HTML, Tailwind CSS, and Vanilla JavaScript**.  

---

## 🎨 Features

### **Core Features**
- Fully **responsive design** (mobile-first approach)  
- Interactive **navigation menu** with automatic close on link click  
- Smooth **preloader animation** with logo  
- **Typed text effect** highlighting different roles (Web Developer, UI/UX Designer, etc.)  
- **Testimonial carousel**  
  - Shows **1 card per slide on mobile**  
  - Shows **2 cards per slide on larger screens**  
- Modern **service and portfolio sections** with hover effects  
- Tailwind CSS for all styling, with **dark/light themes support**  

### **Bonus Interactions**
- Smooth **scroll animations** across sections  
- Hover effects on buttons and links  
- Carousel auto-slides and resizes based on screen width  
- Animated preloader with fade-in/out  

---

## 🛠 Technology Stack

- **Frontend:** HTML5, Tailwind CSS (v4.4.14), JavaScript (Vanilla)  
- **Styling:** Tailwind CSS utilities + animations  
- **Responsive:** Mobile-first design  
- **Animations:** Typed.js-inspired typing effect, carousel transitions, hover effects
